Arquitectura

Clientenavegador→ proxy · Nginx:8080 → :80 (único puerto expuesto)→ api · FastAPI:8000 · UID 1001→ db · PostgreSQL:5432→ volumen pgdatadatos persistentes

Los tres servicios se comunican por nombre en la red Docker interna. La API y la base de datos no publican puertos: solo se llega a ellas a través del proxy. La imagen de la API se construye con un Dockerfile multi-etapa y se publica automáticamente en GHCR; el servidor la descarga y se actualiza solo en cada cambio de main.
